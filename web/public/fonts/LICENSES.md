# Fontes de livro

As fontes abaixo foram baixadas do Google Fonts e ficam servidas localmente em
`/fonts`. Cada familia continua sob a licenca do projeto original; os arquivos
de licenca estao nos repositorios do Google Fonts.

- Newsreader — SIL Open Font License 1.1 — https://github.com/google/fonts/tree/main/ofl/newsreader
- EB Garamond — SIL Open Font License 1.1 — https://github.com/google/fonts/tree/main/ofl/ebgaramond
- Libre Baskerville — SIL Open Font License 1.1 — https://github.com/google/fonts/tree/main/ofl/librebaskerville
- Libre Caslon Text — SIL Open Font License 1.1 — https://github.com/google/fonts/tree/main/ofl/librecaslontext
- Tinos — Apache License 2.0 — https://github.com/google/fonts/tree/main/apache/tinos
- Gelasio — SIL Open Font License 1.1 — https://github.com/google/fonts/tree/main/ofl/gelasio
- Literata — SIL Open Font License 1.1 — https://github.com/google/fonts/tree/main/ofl/literata
- Crimson Pro — SIL Open Font License 1.1 — https://github.com/google/fonts/tree/main/ofl/crimsonpro
