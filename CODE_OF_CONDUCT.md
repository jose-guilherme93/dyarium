# Codigo de conduta

Nos comprometemos a manter este projeto um espaco aberto e acolhedor para
todas as pessoas, independentemente de experiencia, identidade ou origem.

Esperamos de quem participa:

- Seja respeitoso. Critique ideias e codigo, nunca pessoas.
- Assuma boa fe a respeito das intencoes dos outros.
- Aceite feedback e peca desculpas quando errar.
- Foque no que e melhor para o projeto e para quem o usa.

Nao sao aceitos: assedio, comentarios ofensivos, ataques pessoais, divulgacao de
dados privados de terceiros ou interrupcao deliberada de discussoes.

Quem desrespeitar estas regras pode ser advertido ou removido do projeto, a
criterio dos mantenedores. Reporte ocorrencias em privado aos mantenedores.
